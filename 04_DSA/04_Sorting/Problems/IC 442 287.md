# Find All Duplicates in an Array

_Cyclic Sort Pattern – Detailed Notes_

---

## Problem

Given an array `nums` of size `n`  
where:

```java
1 ≤ nums[i] ≤ n
```

Some numbers appear twice.

Return all duplicate numbers.

---

# Core Insight

Since:

- Value range = `1 to n`
    
- Index range = `0 to n-1`
    

We can map:

```java
correctIndex = value - 1
```

This allows us to use **cyclic sort logic**.

---

# Your Complete Code

```java
class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        search(nums);

        List <Integer> duplicate = new ArrayList<>();
        for(int i = 0;i<nums.length;i++){
            int count = nums[i]-1;
            if(i!=count && nums[i]==nums[count]){
                duplicate.add(nums[i]);
            }
        }
        return duplicate;
    }

    public int[] search(int[] nums){

        int i = 0;
        while(i<nums.length){
            int currect = nums[i]-1;
            if(currect>=0 && currect<nums.length && nums[i]!=nums[currect]){
                swap(nums,i,currect);
            }else{
                i++;
            }

        }
        return nums;
    }

    public void swap(int[] nums,int a,int b){
        int temp = nums[a];
        nums[a] = nums[b];
        nums[b] = temp;
    }
}
```

---

# Step 1: Understanding `search(nums)`

```java
while(i<nums.length){
    int currect = nums[i]-1;

    if(currect>=0 && currect<nums.length && nums[i]!=nums[currect]){
        swap(nums,i,currect);
    }else{
        i++;
    }
}
```

### What This Loop Does

It tries to place every number at its correct index.

Since values are from `1 to n`:

```java
correct index = value - 1
```

Example:

value 1 → index 0  
value 2 → index 1  
value 8 → index 7

---

### Why This Condition Is Important

```java
nums[i] != nums[currect]
```

If duplicate exists:

Example:

nums = [2,2]

At index 1:

correct index of 2 = 1

But nums[1] is already 2.

So swapping would do nothing and cause infinite loop.

This condition prevents infinite swapping.

---

### Why Boundary Check Exists

```java
currect >= 0 && currect < nums.length
```

It ensures safety in case input constraints change.

But since problem guarantees 1 ≤ nums[i] ≤ n,  
this will always be true.

---

### After `search()` Completes

All numbers that can be placed correctly are placed.

Duplicates remain at wrong indices.

# Step 2: Duplicate Detection Loop

```java
for(int i = 0;i<nums.length;i++){
    int count = nums[i]-1;
    if(i!=count && nums[i]==nums[count]){
        duplicate.add(nums[i]);
    }
}
```

Let’s break this down carefully.

---

## Line 1

```java
int count = nums[i] - 1;
```

Since range is `1 to n`:

Correct index = value - 1.

---

## Line 2

```java
if(i != count)
```

If index does not match its correct position,  
then element is misplaced.

Example:

Index = 5  
Value = 2  
Correct index = 1

5 != 1 → misplaced.

---

## Line 3

```java
nums[i] == nums[count]
```

If correct position already contains the same number,  
then this is a duplicate.

Why?

Because:

- First occurrence is already at correct index.
    
- Second occurrence could not be placed.
    
- So it stayed somewhere else.
    

That is exactly what this condition detects.

---

# Why No Boundary Check Here?

Because problem guarantees:

```java
1 ≤ nums[i] ≤ n
```

So:

```java
0 ≤ nums[i] - 1 ≤ n-1
```

Therefore:

```java
count is always a valid index.
```

No out-of-bound risk.

---

# Full Logical Flow

1. `search()` rearranges array using cyclic sort.
    
2. Every number tries to go to its correct index.
    
3. If duplicate exists, one copy occupies correct index.
    
4. Other copy cannot be placed.
    
5. After sorting, mismatched indices reveal duplicates.

# Time and Space Complexity

Time Complexity: O(n)  
Each element swapped at most once.

Space Complexity: O(1)  
No extra array used.

# Important Concept

If value range equals array size:

You can use value-to-index mapping.

If range is larger than array size:

You must handle boundary carefully.

# Final Key Takeaway

Cyclic sort works when:

Value range and index range align.

Mapping formula determines everything.

If range starts at 1 → use value - 1  
If range starts at 0 → use value

That is the foundation.
