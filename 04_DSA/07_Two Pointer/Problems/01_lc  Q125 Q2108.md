# 1. LeetCode 125 — Valid Palindrome

## Problem

Given a string `s`:

- Ignore non-alphanumeric characters.
    
- Ignore case sensitivity.
    
- Return `true` if the string is a palindrome.
    

---

## Pattern Used: Two Pointer (Inward Comparison)

We compare characters from both ends and move inward.

---

## Algorithm

1. Initialize:
    
    ```
    start = 0
    end = s.length() - 1
    ```
    
2. While `start < end`:
    
    - Skip non-alphanumeric characters.
        
    - Compare lowercase characters.
        
    - If mismatch → return false.
        
    - Move both pointers inward.
        
3. If loop completes → return true.
    

---

## Implementation

```java
class Solution {
    public boolean isPalindrome(String s) {

        int start = 0;
        int end = s.length() - 1;

        while (start < end) {

            while (start < end && 
                   !Character.isLetterOrDigit(s.charAt(start))) {
                start++;
            }

            while (start < end && 
                   !Character.isLetterOrDigit(s.charAt(end))) {
                end--;
            }

            if (Character.toLowerCase(s.charAt(start)) !=
                Character.toLowerCase(s.charAt(end))) {
                return false;
            }

            start++;
            end--;
        }

        return true;
    }
}
```

---

## Time and Space Complexity

Time Complexity: O(n)  
Space Complexity: O(1)

---

## Key Learning

- Always check pointer condition before accessing characters.
    
- Skip invalid characters before comparison.
    
- Use `start < end`, not `<=`, to avoid unnecessary middle comparison.

# 2. LeetCode 2108 — First Palindromic String in an Array

## Problem

Given an array of strings `words`,  
Return the first string that is a palindrome.  
If none exist, return `""`.

---

## Pattern Used: Two Pointer Inside Loop

Outer loop → iterate over words  
Inner loop → check palindrome using two pointers

---

## Correct Implementation

```java
class Solution {
    public String firstPalindrome(String[] words) {

        for (String word : words) {

            boolean isPalindrome = true;

            int start = 0;
            int end = word.length() - 1;

            while (start < end) {

                if (word.charAt(start) != word.charAt(end)) {
                    isPalindrome = false;
                    break;
                }

                start++;
                end--;
            }

            if (isPalindrome) {
                return word;
            }
        }

        return "";
    }
}
```

---

# Your Logical Mistake

## Mistake: Declaring `isPalindrome = true` Outside the Loop

Incorrect structure:

```java
Boolean isPalindrome = true;

for(String word : words) {
    ...
}
```

### Why This Is Wrong

- Boolean state persists between iterations.
    
- If first word fails:
    
    ```
    isPalindrome = false
    ```
    
- Next word starts with `false` instead of `true`.
    
- Future words may never be evaluated correctly.
    

This causes incorrect results.

---

## Correct Principle

State variables must be reset per iteration.

Correct structure:

```java
for(String word : words) {
    boolean isPalindrome = true;
    ...
}
```

Each word must have its own independent validation state.

---

# Additional Common Mistakes in Palindrome Problems

1. Not breaking early after mismatch  
    → Leads to unnecessary comparisons.
    
2. Using `start <= end`  
    → Middle character does not require comparison.
    
3. Returning inside loop without full validation.
    
4. Forgetting case normalization in string problems.
    

---

# Pattern Recognition for Interviews

Use Two Pointer technique when:

- Checking palindrome
    
- Reversing array/string
    
- Comparing symmetric elements
    
- Removing invalid characters from both ends
    
- Sorted array pair problems (sum, difference, etc.)
    

---

# Mental Model

Palindrome check = Mirror comparison.

Left pointer moves right.  
Right pointer moves left.  
Mismatch means immediate termination.
