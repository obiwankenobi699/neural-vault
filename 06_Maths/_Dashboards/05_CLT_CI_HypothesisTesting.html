Theorem Statement
Central Limit Theorem
For i.i.d. random variables X1, X2, ..., Xn with mean mu and finite variance sigma-squared, as n approaches infinity:

x-bar ~ N(mu, sigma^2 / n)

The standardised form: sqrt(n) * (x-bar - mu) / sigma converges to N(0, 1).
Required Conditions
1. Independent observations
2. Identically distributed
3. Finite mean and variance
Sample Size Rule
n >= 30 for most distributions. n >= 50 for heavily skewed. Any n for Normal populations.
Why It Matters
Justifies t-tests, z-tests, confidence intervals, and the ability to make probabilistic claims about sample statistics.
ML Application
Mini-batch gradient estimates converge to true gradient. Model accuracy on test sets is approximately normally distributed — enabling CI on metrics.

Z vs T Procedure
Use Z when sigma is known (rare). Use T when sigma is estimated from sample (the realistic case). For large n, they are nearly identical.
Width Determinants
Larger n → narrower. Higher confidence level → wider. Higher sigma → wider. You can only control n.
ML Application
Report model accuracy as CI, not a point estimate. Accuracy = 0.92 ± 0.017 (95% CI) on n=1000 test samples is honest. A bare 92% is not.
Nitish's Analogy
Betting Dhoni scores exactly 25 runs — tiny probability. Betting 20-35 runs — much more probable. A range is always more honest than a single number.

Type I and Type II Errors
Two ways to be wrong in hypothesis testing. Reducing one increases the other. The only way to reduce both is to increase sample size.
Error Regions — Power Curve
Alpha (Type I error rate)
0.05
True Difference (effect size)
1.5
Type I Error (alpha)
Reject H0 when it is actually true. False positive. Probability = alpha. Controlled by your choice of significance level.
Type II Error (beta)
Fail to reject H0 when H1 is actually true. False negative. Probability = beta. Decreases as sample size or effect size increases.
Power = 1 - beta
Probability of correctly detecting a real effect. Increases with n, effect size, and alpha.
The Tradeoff
Decreasing alpha (stricter threshold) raises beta. Increasing n is the only way to reduce both simultaneously.
