What is univariate analysis?

One variable at a time. Understand its shape, spread, and centre before comparing anything.

Distribution graphs
KDE PLOT Distinguish species by sepal length

Your exact question. Plot one KDE per species. Overlap shows confusion zone, separation shows you CAN distinguish.

ECDF Empirical cumulative distribution

At each x value: what fraction of data is at or below x. No bin needed, no smoothing. The most honest single-variable graph.

  • Read P(X ≤ x) directly off the y-axis for any x
  • Steeper slope = many values packed in that region

What is multivariate analysis?

Three or more variables together. Find which combination of features separates species best. Answer the question: which features matter most?

All-vs-all and full dataset views

From graph insight to mathematical proof

Graphs tell you what might be true. Statistical tests tell you if it is actually true (not just by chance). Always follow a graph with a test.

Inferential tests — is the difference real?
T-TEST Are two group means significantly different?

Compare mean sepal length of Setosa vs Versicolor. Is the gap real or just sampling noise?

H₀: μ_setosa = μ_versicolor (no difference) H₁: μ_setosa ≠ μ_versicolor t = (x̄₁ - x̄₂) / √(s₁²/n₁ + s₂²/n₂) p-value < 0.05 → reject H₀ → difference is real p-value ≥ 0.05 → cannot reject H₀
  • Use when comparing exactly two groups
  • Assumes roughly normal distribution per group
from scipy.stats import ttest_ind setosa = df[df.species=='setosa']['sepal_length'] versic = df[df.species=='versicolor']['sepal_length'] t, p = ttest_ind(setosa, versic) # p < 0.05 → significantly different
ANOVA Are all three group means different?

Extension of t-test for 3+ groups. Is sepal length different across all three species?

H₀: μ_setosa = μ_versicolor = μ_virginica H₁: at least one mean differs F = variance_between_groups / variance_within_groups Large F → groups differ more than chance allows p < 0.05 → at least one group is different
  • Use when comparing 3 or more groups at once
  • Does not tell you WHICH group is different — need post-hoc test after
from scipy.stats import f_oneway f_oneway(setosa, versic, df[df.species=='virginica']['sepal_length'])
TUKEY HSD Which specific pairs are different?

Post-hoc test after ANOVA. Tells you exactly which species pairs are significantly different from each other.

Tukey HSD output example: Pair p-adj Significant? Setosa vs Versicolor 0.001 YES Setosa vs Virginica 0.001 YES Versicolor vs Virgin. 0.001 YES All three pairs are significantly different in sepal_length → sepal_length is a useful feature to separate all three species.
from statsmodels.stats.multicomp import pairwise_tukeyhsd pairwise_tukeyhsd(df.sepal_length, df.species)
KS TEST Do two distributions have the same shape?

Kolmogorov-Smirnov: compares the full ECDF of two groups. Not just the mean — the entire distribution.

KS statistic = max gap between two ECDFs ECDF 1.0 | Setosa────────────────── 0.8 | ── ↕ D (max gap) 0.6 | Versicolor────────── 0.4 | ──── +────────────────────────── Large D, small p → distributions are different
  • Catches differences in shape, spread, and location all at once
  • More powerful than just comparing means
from scipy.stats import ks_2samp ks_2samp(setosa, versic)

The full EDA workflow — step by step

Every insight question has a natural sequence. Start single, then go wider.

Step by step
STEP 1 — Understand each feature alone (Univariate) ──────────────────────────────────────────────────── Question: What does sepal_length look like by itself? histplot → see raw shape and bins kdeplot(hue=species) → does this ONE feature separate species? boxplot(x=species) → compare medians and spread df.describe() → mean, std, min, max, quartiles Insight: Setosa sepal_length is clearly lower. Versicolor and Virginica overlap here. STEP 2 — Relationships between two features (Bivariate) ──────────────────────────────────────────────────── Question: Do two features together separate better than one alone? scatterplot(x, y, hue=species) → clusters? kdeplot(x, y, hue=species) → 2D density overlap? jointplot → marginal + joint view barplot → mean difference across groups t-test / ANOVA → is the difference statistically significant? Insight: sepal_length + petal_length → Setosa fully separates. Versicolor and Virginica still overlap somewhat. STEP 3 — All features at once (Multivariate) ──────────────────────────────────────────────────── Question: Which combination of features best separates all species? pairplot(hue=species) → scan all pairs, find cleanest scatter heatmap(corr) → which features are redundant? parallel_coordinates → full profile per species Insight: petal_length + petal_width → best separation. sepal_width almost useless alone. petal_length and petal_width are highly correlated (r=0.96) → only need one of them for a model. STEP 4 — Confirm with statistics ──────────────────────────────────────────────────── shapiro → check normality per species per feature ANOVA → are all three species different in this feature? Tukey HSD → which pairs are different? KS test → do the full distributions differ? Insight confirmed: All three species significantly differ in petal_length (p < 0.001, F = 1180).
